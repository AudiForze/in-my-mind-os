La vulnerabilidad de solicitud de falsificación de petición de servidor (SSRF) es una vulnerabilidad de seguridad en la cual un atacante puede enviar una solicitud desde un servidor a través de una aplicación web para acceder a recursos internos del servidor al que la aplicación web tiene acceso. Los atacantes utilizan esta vulnerabilidad para acceder a recursos internos como archivos, bases de datos, servicios y aplicaciones en el servidor comprometido.

Los atacantes pueden explotar esta vulnerabilidad para acceder a información sensible, obtener acceso no autorizado al servidor o comprometer el servidor por completo. Los ataques SSRF pueden ser difíciles de detectar, ya que las solicitudes fraudulentas pueden parecerse a solicitudes legítimas para el servidor.

## Maquinas (PostSwigger)

- SSRF (Basic SSRF against the local server)
- Basic SSRF against another back-end system
- SSRF with blacklist-based input filter 
- SSRF with filter bypass via open redirection vulnerability
- SSRF with whitelist-based input filter 
- Blind SSRF with Shellshock exploitation

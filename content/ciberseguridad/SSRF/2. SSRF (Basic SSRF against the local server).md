Este laboratorio tiene una función de verificación de existencias que obtiene datos de un sistema interno.

Para resolver el laboratorio, cambie la URL de verificación de existencias para acceder a la interfaz de administración en http://localhost/admin y elimine el usuario carlos.

### Maquina

https://portswigger.net/web-security/ssrf/lab-basic-ssrf-against-localhost

### Resolución de la maquina

En esta maquina lo que vamos a hacer es conseguir acceder al panel de administrador haciendo que el servidor nos permita acceder haciendo una petición local (del mismo servidor) a el panel administrador por el puerto `8080` y eliminar al usuario del pobre carlitos

`http://localhost/admi`

Para este vamos a intervenir una petición utilizando `Burpsuit` para cambiar la petición de con esta el lugar a donde nos llevara la pagina.

### Parte Practica

Dentro de Burpsuit vamos a encender el interceptor de peticiones luego pulsamos ctrl+r para mandarlo al interceptor donde cambiaremos la API para insertar `http://localhost/admi`luego vamos a mandarlo para entrar en el panel de administrador, si le damos al botón de render podremos observar un render de la pagina, inspeccionaremos el código en búsqueda de la función de lo que hace el botón de delete.

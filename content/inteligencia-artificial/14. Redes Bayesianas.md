Las **Redes Bayesianas** son un modelo formal utilizado para representar conocimiento y razonar en situaciones donde existe **incertidumbre**. Su fundamento principal es la teoría de la probabilidad, especialmente el teorema de Bayes, combinada con estructuras de grafos dirigidos. A través de este enfoque, es posible describir de manera clara cómo distintas variables se influyen entre sí y cómo el conocimiento sobre unas permite actualizar la probabilidad de otras.

Una red bayesiana se representa mediante un **grafo dirigido acíclico**, en el cual cada nodo corresponde a una variable aleatoria y cada flecha indica una relación de dependencia probabilística. El hecho de que el grafo sea acíclico garantiza que no existan dependencias circulares, lo cual facilita el razonamiento lógico y matemático. Esta estructura permite descomponer una distribución de probabilidad conjunta compleja en varias distribuciones más simples, haciendo el modelo más manejable y comprensible.

Un aspecto central de las redes bayesianas es el concepto de **independencia condicional**. Gracias a este principio, una variable es independiente de otras variables que no están directamente relacionadas con ella, siempre que se conozca el valor de sus variables “padre” en el grafo. Esta propiedad reduce considerablemente la cantidad de información necesaria para describir el sistema completo y es la clave que hace eficientes a las redes bayesianas frente a otros modelos probabilísticos.

Cada variable de la red está asociada a una **tabla de probabilidad condicional**, que especifica la probabilidad de que dicha variable tome ciertos valores dado el estado de sus variables causales. Estas tablas pueden construirse a partir de datos estadísticos o del conocimiento experto, y constituyen la parte cuantitativa del modelo. Una vez definidas, la red permite actualizar creencias cuando se obtiene nueva evidencia, ajustando las probabilidades de manera coherente con las leyes de la probabilidad.

La **inferencia probabilística** es uno de los principales usos de las redes bayesianas. Mediante este proceso, se pueden calcular probabilidades desconocidas a partir de información parcial, responder preguntas de diagnóstico, realizar predicciones o encontrar explicaciones plausibles de ciertos eventos observados. Este razonamiento es especialmente valioso en contextos donde no se dispone de información completa, como en el diagnóstico médico o en sistemas de apoyo a la toma de decisiones.

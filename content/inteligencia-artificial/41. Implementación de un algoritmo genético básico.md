En esencia, se trata de maximizar una función de dos variables reales, ( f(x, y) ), donde cada variable se encuentra acotada dentro de un intervalo específico y requiere una precisión de cuatro decimales. Este planteamiento no es casual: permite evidenciar las ventajas de los algoritmos genéticos frente a los métodos numéricos tradicionales. Mientras estos últimos dependen fuertemente de un valor inicial y pueden estancarse en máximos locales, el enfoque evolutivo no necesita un punto de partida privilegiado y es capaz de explorar el espacio de soluciones de manera global, acercándose a soluciones óptimas mediante un proceso iterativo inspirado en la evolución natural.

Desde el punto de vista metodológico, el algoritmo genético que se estudia se caracteriza por emplear una representación binaria de las soluciones. Cada posible solución del problema, es decir, cada par de valores ((x, y)), se codifica como una cadena de bits denominada cromosoma. Para lograr la precisión requerida en cada variable, se calcula la longitud de la cadena binaria necesaria para representar los valores dentro de sus respectivos intervalos. En el caso descrito, la variable (x) se representa con 18 bits y la variable (y) con 15 bits, lo que da lugar a cromosomas de 33 bits en total. Esta codificación permite transformar el problema continuo en uno discreto, donde las operaciones genéticas pueden aplicarse de forma directa.

Un aspecto central del proceso es el mapeo entre el genotipo y el fenotipo. El genotipo corresponde a la cadena binaria, mientras que el fenotipo es el conjunto de valores reales de (x) y (y) que dicha cadena representa dentro del dominio del problema. Este mapeo se realiza mediante una transformación matemática que convierte el valor binario en un número real dentro del intervalo permitido. Una vez obtenidos los valores reales, es posible evaluar la función objetivo, que determina qué tan buena es cada solución candidata.

El algoritmo evoluciona a través de generaciones. Inicialmente, se genera una población de individuos de manera aleatoria. Cada individuo se evalúa mediante la función objetivo y se le asigna un valor de aptitud o fitness, que es una transformación del valor de la función objetivo diseñada para facilitar el proceso de selección. A partir de aquí se activa el ciclo evolutivo, el cual constituye el núcleo del algoritmo genético. En cada generación se seleccionan individuos con base en su aptitud, privilegiando a los más aptos mediante un mecanismo proporcional, comúnmente conocido como selección por ruleta. Estos individuos seleccionados se combinan mediante el operador de cruza, donde se intercambian segmentos de sus cadenas binarias en un punto de corte, generando nuevos descendientes. Posteriormente, se aplica el operador de mutación, que introduce cambios aleatorios en algunos bits con una probabilidad baja, lo cual garantiza la diversidad genética y evita la convergencia prematura.

La nueva población generada pasa nuevamente por el proceso de decodificación y evaluación, y el ciclo se repite durante un número determinado de generaciones. A lo largo de este proceso, la población tiende a mejorar progresivamente, ya que los individuos con mayor aptitud tienen mayor probabilidad de transmitir sus características a las siguientes generaciones. Este comportamiento emula los principios de la selección natural y permite que el algoritmo explore el espacio de soluciones de manera eficiente.

En cuanto a la estructura de datos, el algoritmo se apoya en varias representaciones fundamentales: la matriz de cromosomas que contiene los genotipos de todos los individuos, la matriz de fenotipos que almacena los valores reales de las variables de decisión, el vector de valores de la función objetivo y el vector de aptitudes. Estas estructuras permiten organizar la información y facilitan la aplicación de los operadores genéticos y la evaluación del desempeño de cada individuo.

En conjunto, el contenido desarrolla no solo la implementación técnica de un algoritmo genético, sino también los fundamentos conceptuales de la computación evolutiva. Se abordan temas como la codificación de soluciones, el mapeo genotipo-fenotipo, la función objetivo, la aptitud, los operadores genéticos y el proceso evolutivo iterativo. Todo ello se articula para resolver un problema de optimización de manera robusta, mostrando cómo los algoritmos genéticos constituyen una herramienta poderosa cuando se enfrentan a espacios de búsqueda complejos donde los métodos tradicionales pueden fallar.

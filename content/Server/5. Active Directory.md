Active Directory ( AD ) es un servicio de directorio desarrollado por Microsoft para redes de dominio de Windows . Los sistemas operativos Windows Server lo incluyen como un conjunto de procesos y servicios . Originalmente, solo la administración centralizada de dominios utilizaba Active Directory.

En otras palabras Active Directorio es un servicio o caracterisitca que implementaremos en nuestro servidor para poder gestionar diferentes equipodes dentro de un mismo dominio. Tendremos un servidor principal y posteriormente dispostivos allegados al servidor que seran los clientes, quienes capturaran las reglas y normas del servidor a traves de politicas y compartiran archivos atraves de redes SMB bajo el puerto 25. 

![[Pasted image 20260906160320.png]]

Para eso nos iremos a nuestro Dashboard y luego iremos a agregar roles y caracteristicas. Luego en el menu que nos aparecera vamos a darle Skip > Instalacion de Roles > Seleccionamos nuestro servidor > Luego seleccionamos Servicio de dominio de active directory 

![[Pasted image 20260906160639.png]]

Luego Next > Next > Next > Permitir reiniciar en caso de ser necesario 
![[Pasted image 20260906160808.png]]

Luego de esto vamos a ir a nuestro Dashboard en una bandera que tendremos en la barra superior, dale click y luego click en **Promote this server to a domain controller**
![[Pasted image 20260906160939.png]]

Despues seleccionaremos "agregar un nuevo bosque" y agregamos un nombre a nuestro nueva raiz.

![[Pasted image 20260906161212.png]]

Luego nos pedira agregar una password donde yo recomiendo utilizar la misma password mientras estemos en ambientes de prueba. (En un servidor real NUNCA se hace esto). Continuando con el proceso daremos a Next 3 veces e instalar para poder terminar la configuracion. Aqui si se podria reiniciar nuestro servidor.

Luego de esto si todo esta configurado de forma correcto deberiamos ver en la pantalla de inicio el nombre de nuestro servidor junto a la usuario.

Ahora vamos a crear nuestra maquina virtual que funcionara como nuestro servidor de Active Directory sobre el cual vamos a ejecutar las politicas que permitiran gestionar los ordenadores clientes. 

### Crear la Maquina virtual
Para esto vamos a ir a la parte de arriba de nuestro programa y daremos click sobre crear nueva maquina, importaremos nuestro ISO.
![[Pasted image 20260906144405.png]]

Luego vamos a seleccionar la memoria y cpu que nuestra maquina va a ocupar, lo recomendable es usar 1-2 cpu y de memoria de ram entre 1024 y 4096 mb.
![[Pasted image 20260906144509.png]]

Continuando seleccionado el espacio que pueda llegar a ocupar nuestro windows server en nuestro sistema. Para eso yo recomiendo hacerlo con un limite en un virtual de 30gb o utilizar un custum storage.

![[Pasted image 20260906144625.png]]

Por ultimo para completar la configuracion vamos a declarar un nombre y la configuracion de red. El nombre pueden elegir el que gusten pero la red es mas delicado. Mi recomendacion es hacerlo en Nat que le asocia una direccion ip propia a la computadora pero el trafico pasa sobre nuestra computadora fisica. Si lo ponemos como Bridge o adaptador puente, esta utilizara una ip de nuestra red de dispositivos local (LAN) donde estemos conectados.

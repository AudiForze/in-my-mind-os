
Ahora vamos a configurar los equipos y clientes que usaran nuestros usuarios dentro de la red de nuestro active directory. Para esto vamos a desplazarnos a **Tool > Active Directory Users and computers**
![[Pasted image 20260906215540.png]]

Luego dentro del menu vamos a crear una nueva unidad organizativa y esto se hace cuando damos click derecho sobre nuestro redinterna que habiamos creado y luego vamos a **nuevo > unidad organizativa.**

![[Pasted image 20260906215826.png]]

Este proceso lo haremos tres veces, ya que tendremos el principal y luego donde iran nuestros estudiantes o personal, y otro para nuestros equipos(computadores).

![[Pasted image 20260906220055.png]]


![[Pasted image 20260906220238.png]]

Luego de esto vamos a crear nuestro primer usuarios que podemos crear directamente en nuestra carpeta haciendo click derecho en **New > User** o:
![[Pasted image 20260906220713.png]]

Luego crearemos un equipo para este usuario, que sera el dispotivo que este va a utuilizar. Para esto vamos a crear un nuevo equipo o computador, haciendo click derecho sobre la unidad de equipos y seleccionando computador 

![[Pasted image 20260906221207.png]]

Luego rellenamos los datos segun correspondan pero lo mas importante es dar a **change o cambiar** para asignarle la maquina a un usuarios en especifico y que solo el la pueda usar.

![[Pasted image 20260906221353.png]]

Despues iremos a configuracion avanzada para buscar el nombre del usuario que usara el equipo y le daremos a buscar, para luego seleccionar la persona. Y guardaremos los cambios.

![[Pasted image 20260906221505.png]]

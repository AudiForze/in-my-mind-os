qqAhora vamos a crear carpetas para compartir informacion entre los estudiantes de forma publica. Esto permite compartir archivos para que todos los estudiantes o miembros del grupo de estudiantes de nuestro servidor tengan acceso a archivos que nosotros compartiremos y luego podremos gestionar lo que cada uno hace.

### 2. Vamos a configurar el File and Storage Service
Para estamos a agregar un nuevo rol y caracteristica, donde sleccionaremos **file and Storage Service > File And iCSi > File Server Resousce Manager** y la agregamos al servidor.

![[Pasted image 20260907113855.png]]
Luego presionaremos Aceptar, 3xNext y por ultimo Install.

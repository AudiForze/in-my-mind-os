### Agregamos un nuevo adaptador de RED.

En este paso vamos a agregar un nuevo adaptador de red y crear una nueva red virtual. Normalmente esto se hace de forma rapida desde la configuracion de la maquina y posteriormente nos vamos a redes y por ultimo nuevo adaptador y seleccionamos red interna.

1. Configure Machine
2. Go to **Networks**
3. New Adapter (NIC)

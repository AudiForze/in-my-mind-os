La máquina virtual basada en el kernel (KVM) es una función de software que se puede instalar en máquinas Linux físicas para crear máquinas virtuales. Una máquina virtual es una aplicación de software que actúa como un ordenador independiente dentro de otro ordenador físico. Comparte recursos como ciclos de CPU, ancho de banda de red y memoria con la máquina física. KVM es un componente del sistema operativo Linux que proporciona soporte nativo para máquinas virtuales. Está disponible en las distribuciones de Linux desde 2007. [Fuente](https://aws.amazon.com/what-is/kvm/)

# Guía: Instalación y configuración de KVM en Arch/Omarchy

## 1. Verificar soporte de virtualización

Confirma que tu CPU soporta virtualización y que está habilitada en la BIOS/UEFI:

```bash
LC_ALL=C lscpu | grep Virtualization
```

Debe mostrar `VT-x` (Intel) o `AMD-V` (AMD). Si no aparece nada, entra a la BIOS y habilita `Intel VT-x` o `SVM Mode` (AMD).

## 2. Instalar los paquetes necesarios

```bash
sudo pacman -S qemu-full virt-manager virt-viewer dnsmasq vde2 openbsd-netcat libguestfs ebtables iptables-nft
```

> **Nota:** `bridge-utils` fue removido de los repos oficiales de Arch (obsoleto). Sus funciones las absorbió `iproute2`, que ya viene por defecto en el sistema base. No hace falta reemplazarlo por nada.

Si quieres algo más liviano (solo x86_64, sin soporte multi-arquitectura), usa `qemu-desktop` en vez de `qemu-full`.

## 3. Habilitar y arrancar libvirtd

```bash
sudo systemctl enable --now libvirtd.service
```

Verifica que quedó activo:

```bash
sudo systemctl status libvirtd
```

## 4. Agregar tu usuario al grupo libvirt

```bash
sudo usermod -aG libvirt $USER
```

Cierra sesión y vuelve a entrar (o reinicia) para que el cambio de grupo tenga efecto. Confirma con:

```bash
groups $USER
```

## 5. Activar la red NAT por defecto

```bash
sudo virsh net-autostart default
sudo virsh net-start default
```

Verifica que está activa:

```bash
sudo virsh net-list --all
```

## 6. Ejecutar virt-manager

Desde terminal:

```bash
virt-manager
```

O desde el menú de aplicaciones, buscando "Virtual Machine Manager".

Deberías ver una conexión llamada **QEMU/KVM** (o "localhost (QEMU)"). Si aparece con candado o "not connected", haz doble clic para conectar.

**Si da error de conexión/permisos:** revisa que `libvirt` aparezca en `groups $USER` y que `libvirtd` esté `active (running)`.

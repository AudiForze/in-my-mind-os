Una de las cualidades que tenemos en los servidores es que puedan distruibuir las direcciones ip y actuar como servidores DHCP una vez las maquinas entran al servidor y como es parte de lo que esta en la planificacion la haremos desde ahora. De esta forma segun entre y se registre cada usuario, entonces cada equipo tomara una direccion ip dada por el servidor.

![[Pasted image 20260906221822.png]]

### Agregar Rol y caracteristica
Para esto vamos al Dashboard y daremos a **Next** tres veces hasta entrar a las caracteristicas para descargar donde buscaremos DHCP Server y la agregamos dandole a **click > Next > Install**
![[Pasted image 20260906222015.png]]

### Configuracion
Luego de la instalacion vamos a proceder con la configuracion, para esto volvemos a nuestra bandera y damos click en configurar DHCP server.

![[Pasted image 20260906222255.png]]

Continuando utilizaremos las credenciales de nuestro active directory. Y aunque parezca listo falta determinar el rango de ip donde actuara nuestro servidor.

![[Pasted image 20260906222406.png]]

Para esto vamos a ir a **Herramientas > DHCP** 
![[Pasted image 20260906222547.png]]

Dentro de este menu vamos a dirigirnos a **IPv4** que es la tegnologia que utilizaremos. Despues dare click y luego click en **Action > New Scope > Next**

![[Pasted image 20260906222856.png]]

Aqui pondremos el rango de direccion ip que utilizara nuestro servidor, esto es importante que este de acuerdo con la configuracion que tenemos con nuestros adaptadores de red.

![[Pasted image 20260906223049.png]]

Adaptador de Red
![[Pasted image 20260906223323.png]]

Luego configuramos la gateway, que suele ser la punto 1 de cualquier red.
![[Pasted image 20260906223545.png]]

Luego de darle a **Next** nos encontraremos con un menu como este donde pondremos nuestra direccion ip. 

![[Pasted image 20260906223840.png]]

### Comprobaccion de TODO
Si todo esta funcionando bien entonces cuando entremos a nuestro nuevo computador como cliente deberiamos poder ver un menu como este donde nos permitira unirnos a la red que creamos de AD.

![[Pasted image 20260906224153.png]]

En la computadora del cliente vamos **Acerca De > Cambiar el nombre de este dispositivo (avanzado)**.

![[Pasted image 20260906224425.png]]

Y aqui vamos a agregar el nombre del equipo que registramos en el servidor para esa maquina y posteriormente nos pedira un usuario con permisos de agregar usuarios. Para este utilizaremos el mismo de **administrator**. Y reiniciaremos

![[Pasted image 20260906224939.png]]

Al momento de reiniciar vamos a irnos a Otros Usuarios y si todo a salido bien entonces veremos el nombre de nuestra red del Active Directory y pondremos el nombre y las password asociada al equipo con el que registramos la maquina.

![[Pasted image 20260906225232.png]]

Y ahora con esta ultima configuracion entonces si tenemos nuestro sistema funcionando y al momento de entrar deberiamos ver un mensaje como este:

![[Pasted image 20260906225905.png]]

Y nuestro servidor DHCP se encuentro funcionando

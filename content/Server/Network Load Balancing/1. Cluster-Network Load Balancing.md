Un clúster NLB (Network Load Balancing) es una tecnología de Windows Server que permite conectar varios servidores para que atiendan solicitudes de clientes utilizando una misma dirección IP virtual.

### 1. ¿Cómo funciona un clúster NLB?
Imagina que tienes una página web que recibe miles de visitas. Si todas las solicitudes llegan a un solo servidor, este podría saturarse. Con NLB puedes configurar varios servidores para atender las conexiones.
```
			 Clientes
	Solicitan acceso a una página web
			    |
		Solicitudes de red
				|
			Clúster NLB
	IP virtual: 10.0.0.3
	Recibe el tráfico dirigido al servicio
				|
	|-------------------------|
	|		                  |
servidor 1                 servidor 2
```

#### Paso a paso

1. El cliente realiza una solicitud. Por ejemplo, abre una página web utilizando la IP virtual `10.0.0.3`.

2. El clúster recibe el tráfico. Los nodos NLB utilizan un mecanismo distribuido para determinar qué servidor atenderá cada conexión.

3. Un servidor procesa la solicitud. El servidor elegido responde al cliente.

4. NLB supervisa la disponibilidad de los nodos. Si un servidor deja de participar, los nodos restantes ajustan la distribución del tráfico.
